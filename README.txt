DOTI Working Prototype v2

Features:
- Customer/household registration and login
- Waste collector registration and login
- Customer dashboard
- Pickup requests (instant/scheduled)
- Waste recording and demo Doti Points
- Demo utility-point redemption
- Collector dashboard
- Collector job acceptance and completion
- Browser localStorage persistence

Run:
1. Extract the ZIP.
2. Open index.html.
3. Create a customer account.
4. Create a separate collector account.
5. Submit a pickup as customer.
6. Log out and sign in as collector to accept/complete it.

This is a front-end prototype, not a production system. Data is stored locally in the browser. Production requires secure authentication, cloud database/API, KYC, GPS/maps, real notifications, payments, utility integrations, admin controls and secure points accounting.
