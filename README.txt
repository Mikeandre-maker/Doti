DOTI Prototype
================
A browser-based functional prototype for the DOTI waste-to-value platform.

Included flows:
- Dashboard and Doti Points wallet
- Request instant/scheduled waste pickup
- Record sorted waste by material and kilograms
- Automatic demo points calculation
- Utility payment using Doti Points
- Recent activity / impact dashboard

How to run:
1. Open index.html in Chrome, Edge, Firefox, or Safari.
2. No server or installation is required.
3. This is a front-end pilot prototype; real authentication, GPS, collector dispatch,
   payment-provider APIs, database, notifications and utility integrations still need
   a production backend.
